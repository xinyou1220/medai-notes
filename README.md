# 醫療人工智慧概念講義（MedAI Notes）

這是一個以主題頁為單位、整理醫療人工智慧概念的靜態講義網站。每個主題都依照統一的結構撰寫：摘要、背景與動機、核心原理、臨床應用案例、限制與風險、重點整理、參考資料。專案透過 `AGENTS.md` 定義寫作規範、頁面結構與新增內容的流程，讓 AI 程式助理與人工編輯都能依照同一套規則持續擴充內容。

- 網站：<https://xinyou1220.github.io/medai-notes/>
- 規範文件：[AGENTS.md](AGENTS.md)

另有名詞表，收錄各主題中的專有名詞。

## 快速開始

本專案不需要安裝任何套件，也沒有建置步驟。

- **本機瀏覽**：直接以瀏覽器開啟 `index.html`。
- **新增主題**：
  ```
  node scripts/new-topic.mjs <slug> "<中文標題>" "<英文標題>" <分類 id> <入門|進階>
  ```
- **規則檢查**：
  ```
  node scripts/check.mjs
  ```

新增或修改內容的完整流程，請見 [AGENTS.md](AGENTS.md) 第 7 節。

## 專案結構

```
index.html / glossary.html / about.html   首頁、名詞表、關於本站
topics/          主題頁（一個主題一個檔案）
data/            網站設定、主題登錄表、名詞表
assets/          樣式與共用程式
templates/       主題頁範本
scripts/         建立主題與規則檢查的工具
```
